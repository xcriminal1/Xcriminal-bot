# `Xcriminal setup`

Initialize `~/.Xcriminal/Xcriminal.json` and the agent workspace.

Related:
- Getting started: [Getting started](/start/getting-started)
- Wizard: [Onboarding](/start/onboarding)

## Examples

```bash
Xcriminal setup
Xcriminal setup --workspace ~/clawd
```

To run the wizard via setup:

```bash
Xcriminal setup --wizard
```
